# Itumeleng Dintwe — Editorial Web Development Portfolio

Redesigned to match the supplied light, minimalist CSS visual direction: white background, near-black type and accents, Playfair Display serif display headings, Inter sans-serif body, animated navigation underlines, outlined monochrome CTAs and a centered introduction.

## Files
- `index.html`: semantic website with four client case studies
- `styles.css`: entire responsive visual treatment
- `main.js`: active filters, accessible case-study dialog, mobile navigation and reading progress
- `assets/George_Dintwe_Web_Developer_Resume.pdf`: downloadable one-page web development résumé

## Launch
Open `index.html` locally, or run `python -m http.server 8000` from this directory and open `http://localhost:8000`.

## Deploy
Publish the folder to GitHub Pages, Vercel, Netlify or a static hosting service; preserve the `assets/` folder. There is no build process. Google Fonts require internet access; local fallback fonts are configured.
